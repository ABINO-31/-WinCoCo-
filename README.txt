WinCoCo APK
A) Android Studio: File > Open > this folder > Build > Build APK(s).
B) Without Android Studio: upload this folder's content to a new GitHub repository,
   open Actions > "Build APK" > Run workflow, then download the artifact WinCoCo-apk (app-debug.apk).
Install the APK on the phone (allow "install unknown apps"). The app works fully offline.
